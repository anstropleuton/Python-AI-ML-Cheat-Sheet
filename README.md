# 🛠 How to Recreate the Final PDF

# 📋 Step-by-Step Replication Guide

### 1️⃣ Open the Repository

- Open the project folder in **VS Code**
- Use a **light theme** (recommended: `Default Light Modern`)
  This ensures clean formatting when copying into Word.

---

### 2️⃣ Prepare the Word Document

- Open **Microsoft Word**
- Create a new blank document
- You will paste each Markdown page one by one

---

### 3️⃣ For Each Page (Page-X.md)

1. Open `Page-X.md`
2. Press `Ctrl + Shift + P`
3. Select: `Markdown: Open Preview`
4. Click inside the Preview panel
5. Select all: `Ctrl + A`
6. Copy: `Ctrl + C`
7. Switch to Word
8. Paste using:
   - **Paste → Keep Source Formatting**
   - Or: `Ctrl + V` → Press `Ctrl` (tap) → Press `K`

Repeat for all pages.

---

### 4️⃣ Final Formatting in Word

After all pages are pasted:

- Select all text: `Ctrl + A`
- Reduce font size **3 times**
- Set:
  - Line spacing: `1.15`
  - Spacing after paragraphs: `0 pt`

- Layout settings:
  - Margins → **Narrow**
  - Columns → **Two columns**

Ensure each major page starts on a **new page**.

---

### 5️⃣ Export to PDF

- Go to `File → Save As`
- Choose `PDF` format
